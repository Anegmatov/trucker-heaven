# DriveOps Frontend

Static MVP dashboard for the Nashville rental office.

## Run locally

Use a static server, for example VS Code Live Server.

Open:

```text
index.html
```

Then set API details inside the Settings page:

```text
Backend API base URL: http://localhost:3000
Admin API key: same as backend ADMIN_API_KEY
```

## Main screens

- Dashboard
- Customer Catalog
- Admin Fleet
- Reservations
- Settings

## Admin fleet flow

1. Enter vehicle details.
2. Upload one or more photos.
3. Click Save car.
4. The car appears in Admin Fleet and Customer Catalog if status is Available.
