# Owner Confirmation Questions

Please answer these before any map-first implementation or data mapping begins.

1. Please reattach the manager map at an accessible path or as an image attachment; the referenced file was unavailable during this audit.
2. What are the exact active space labels and ranges? Confirm whether the reported ranges 10–90, 101–196, and 197–204 are correct, including every intentional gap.
3. Which direction does numbering run on each row, and are any row numbers reversed or duplicated on purpose?
4. What do each handwritten color, symbol, outline and arrow mean?
5. Which exact spaces are Daily, Weekly (if used), Monthly, Company Only, Shop Controlled, Bobtail, Tractor + Trailer, Tractor Only, Trailer Only, overflow, blocked, or permanently unavailable?
6. Are spaces 197–204 active, and if so what use and vehicle eligibility do they have?
7. Which spaces may customers reserve publicly? Which must remain staff-only, company-only, shop-controlled, or physically blocked?
8. Can a customer select an exact spot, or should ParkingOps automatically assign one? Are any spaces pre-assigned to companies or drivers?
9. Do different physical sections require distinct customer arrival/exit instructions, entrances, rates, closure rules, or staff responsibility? This determines whether more than one internal area is justified.
10. Which drawn buildings, office/shop areas, entrances, exits, lanes, arrows, islands and turnarounds must appear on the customer-facing map, and which are staff-only?
11. Are any rows overflow-only, seasonal, temporarily closed, too small for a category, or unavailable during shop operations?
12. What prices and rules apply to each parking use: daily, weekly, monthly, special/company, fees/taxes, and public visibility?
13. Should the published map be printable, and should it include staff-only operational labels or a customer-safe version only?

No answer should be inferred from unclear handwriting. Existing historical labels and assignments remain authoritative until the owner approves a mapping.
