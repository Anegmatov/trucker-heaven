# Map geometry

Geometry is stored as percentage-based vector layout elements in the normal published-layout model, not as a photo background. The canonical source is `backend/data/trucker-heaven-real-lot-layout.v1.json`; calibrated v2 follows the portrait printed-map arrangement: split west/east exterior runs, paired upper-center bobtail columns, `197–204` directly above `73–80`, lower Shop bays, and the lower Company / ITM run. It defines buildings, open circulation lanes, islands, barriers, entrance, exit, direction labels, and property boundary.
