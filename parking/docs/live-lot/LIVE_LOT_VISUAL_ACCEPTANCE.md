# Live Lot visual acceptance

Use this checklist with an authenticated OWNER and STAFF account when local data is available:

- Desktop: toolbar wraps cleanly; published map preserves placement and readable numbered-space hit areas; selected panel does not clip.
- Status: Available, Reserved, Occupied, Blocked, and Inactive have text and distinct visual treatment; monthly remains secondary; future reservation and warning markers do not replace status.
- Future view: the evaluated instant and lot timezone are visible, the future notice is prominent, and Return to now restores current state.
- Warnings: summary count, map/list marker, and detail text agree; STAFF has no repair link.
- Fallback: a missing map and unplaced spaces remain selectable; phone width shows the searchable/filterable all-space list rather than a tiny map.
- Search: grouped results distinguish records, keyboard navigation works, and actions route only to existing compatible workflows.
- No payment, fabricated records, draft geometry, raw layout IDs, or physical-map import controls appear in Live Lot.
