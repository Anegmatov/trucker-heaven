# Live Lot responsive behavior

Desktop keeps the published map and selected-space panel side by side within the Phase 1 application shell. The panel is sticky while the manager scans the map, and the toolbar wraps rather than creating oversized control cards.

On tablet widths, the selected-space panel becomes a closeable right-side drawer so the map has the available workspace. Search groups reduce to two columns.

On phones, the map is intentionally hidden instead of forcing tiny hit targets. The fallback list becomes the primary all-space operational view, including spaces that have map placement. The selected detail becomes a full-screen panel; filters, search, warning state, and the reservation route remain available without page-wide horizontal scrolling.
